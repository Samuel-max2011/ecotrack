# EcoTrack

EcoTrack is a web project focused on environmental awareness and encouraging responsible waste management.

## About the Project

EcoTrack was created to use technology to promote environmental awareness and encourage people to take better care of their environment.

## Features

- Environmental awareness information
- Waste management information
- About section
- Team section
- Animated counters
- Progress indicators
- Responsive design
- Interactive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Bootstrap

## Getting Started

### Requirements

No special server is required for the current version of EcoTrack.

You only need:

- A web browser
- The EcoTrack project files

### Installation

1. Clone or download this repository.
2. Open the project folder.
3. Open the main HTML file in your web browser.
